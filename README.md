# Mango Extensions Collection

Hey! 👋 Welcome to this collection of extensions made for Mango. If you're using Mango and want to add some extra functionality, you might find something useful here.

## Important Stuff

Before you dive in, here are a few things to keep in mind:

- **Check the README for Each Extension:** Every extension has its own README file. Make sure you read that before using the extension! It explains what the extension does, which Mango version it needs, and any settings or details you should know about.

- **Use the Releases:** Ready-to-install `.grove` files are published through the repository's **Releases**. The source directories in this repository contain the extension code and documentation.

- **Compatibility:** Some extensions may only work with certain versions of Mango. You’ll find compatibility information in the README of the specific extension.

- **Test New Versions:** Extensions can affect how Mango displays or handles messages, so it’s always a good idea to test a new version before relying on it.

## What’s Inside?

Here’s a quick list of the extensions you can find here:

- **LinkGuard:** Checks links in IRC messages against local threat lists, marks potentially unsafe links, and can optionally defang them.

- **DigitalTouch** Create live animated touch messages with disappearing ink and touch effects.

I’ll keep adding more as I work on them!

## Installation

Download the `.grove` file for the extension you want from the latest matching **Release** and install it in Mango.

Check the extension's own README for additional information and available settings.

## Disclaimer (aka "Please Don’t Break Your Mango")

These extensions are personal projects and may still change as Mango and Grove evolve.

I try to make sure everything works correctly, but if something goes wrong, I can’t take responsibility for it. Test new versions first and keep in mind that extensions can modify how messages are displayed or processed.

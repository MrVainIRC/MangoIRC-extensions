# DigitalTouch v0.1.0

Initial public release of DigitalTouch for Mango 3.1.

DigitalTouch is a composer extension for creating animated touch messages with drawing tools, touch effects, replay, and multiple export formats.

## Highlights

- Live animated drawing canvas
- Apple Pencil pressure support when available
- Mouse, trackpad, touch, and finger input
- Ink, Neon, Comet, and Electric drawing styles
- Velocity-aware fading strokes
- Rounded stroke endings
- Tap, Fireball, Kiss, Heartbeat, and Heartbreak effects
- Editable animation replay
- New strokes and effects can be inserted at the current replay position
- Adjustable stroke size and playback speed
- Optional looping for animated image formats
- Configurable export size and frame rate
- Small, Balanced, High, Max, and Custom export presets
- GIF, APNG, WebP, WebM, and MP4 export
- Bundled pure JavaScript VP8L WebP encoder
- Upload through Mango's configured uploader

## Requirements

- Mango 3.1 or newer

## Installation

Download the `DigitalTouch-0.1.0.grove` file from this release and install it in Mango.

See the DigitalTouch README for configuration and usage details.

# Changelog

## 0.1.0

Initial release of DigitalTouch.

- DigitalTouch-style animated drawing
- Live canvas rendering
- Editable replay with timeline-position insertion
- Action-only animation timeline
- Apple Pencil pressure-aware input
- Four fading ink tools: Ink, Neon, Comet, and Electric
- Velocity-aware stroke fading
- Tap, Fireball, Kiss, Heartbeat, and Heartbreak effects
- Replay speed control
- Loop toggle in the composer for animated exports
- Persistent export settings
- Square GIF, WebP, APNG, WebM, and MP4 export
- Bundled pure-JavaScript WebP encoder
- Mango composer upload integration
